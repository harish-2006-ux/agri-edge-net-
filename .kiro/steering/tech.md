# Core Engineering Specifications & Mathematical Layout

## 1. Multimodal Cross-Attention Fusion Core

Instead of simple end-stage vector concatenation, the system uses an intermediate cross-attention core. Normalized time-series meteorological embeddings act as Queries ($Q$) that actively scan and weigh the spatial feature maps (Keys $K$ and Values $V$) generated by the vision stream.

$$
\text{Attention}(Q, K, V) = \text{Softmax}\left(\frac{Q K^T}{\sqrt{d_{\text{embed}}}}\right) \cdot V
$$

## 2. Multi-Task Joint Optimization Function

To optimize for multiple targets at the same time without allowing one loss gradient to disrupt another, the network architecture is governed by a combined multi-task loss function regulated via a Huber loss constraint:

$$
\mathcal{L}_{\text{total}} = \alpha \cdot \mathcal{L}_{\text{disease}} + \beta \cdot \mathcal{L}_{\text{yield}} + \gamma \cdot \mathcal{L}_{\text{cycles}} + \delta \cdot \mathcal{L}_{\text{prescription}}
$$

- $\mathcal{L}_{\text{disease}}$: Cross-Entropy Loss for categorical pathology identification.
- $\mathcal{L}_{\text{yield}}$: Huber Loss (Smooth Absolute Error) to protect continuous yield calculations from being skewed by sudden weather anomalies.
- $\mathcal{L}_{\text{cycles}}$: Categorical Cross-Entropy to determine remaining annual planting windows.
- $\mathcal{L}_{\text{prescription}}$: Binary Cross-Entropy with Logits Loss for multi-label resource recommendations (Water, Nitrogen, Phosphorus, Potassium updates).

## 3. Market Elasticity Simulation Function

The economic planning module uses an explicit econometric simulation function ($R_{\text{sim}}$) to calculate profit fluctuations based on shifting market data:

$$
R_{\text{sim}}(\Delta P) = \left[ \hat{Y}_{\text{model}} \times \left( P_{\text{current}} \times \left(1 + \frac{\Delta P}{100}\right) \right) \right] - C_{\text{production}}
$$

Where:
- $\hat{Y}_{\text{model}}$ is the predicted yield volume
- $P_{\text{current}}$ is the live wholesale rate pulled from data scrapers
- $\Delta P$ is the percentage shift parameter simulated by the user (-30% to +30%)
- $C_{\text{production}}$ is the fixed cost tracking baseline production inputs

# Built-In Architectural Defenses

## Defense Against Gradient Drowning (Fixing Defect 1)

Because image data contains vastly higher density than numerical weather lists, standard backpropagation pathways tend to optimize the vision parameters rapidly and ignore weather data. EdgeAgri-Net implements independent, dual-channel Layer Normalization blocks on both inputs before they meet, balancing their scales and forcing the AI's brain to give both streams equal weight.

## Defense Against Attention Smearing (Fixing Defect 2)

Mixing 1D timelines with 2D image grids can confuse Explainable AI (Grad-CAM) tracking weights, resulting in blurry, smeared heatmaps. EdgeAgri-Net passes the visual feature map through an Adaptive Global Average Pooling Layer to collapse the spatial dimensions into a clean, unified "Global Visual Summary" vector before the cross-attention layer queries it. This step keeps the attention weights stable and produces sharp, localized heatmaps pointing directly to crop lesions.
